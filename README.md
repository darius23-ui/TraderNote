# TraderNote
 Desktop portfolio tracker, risk engine &amp; trading journal in Python (CustomTkinter, SQLite, yfinance). Features TWR/XIRR, cash-flow-matched benchmark   │ comparison, multi-currency FX impact, risk metrics (Drawdown, Volatility, Beta), Trading 212/IBKR/XTB import, FIFO/Weighted-Avg tax reports,   │ background Telegram alerts &amp; 120+ automated tests.
